## Key Technical Decisions

- **Server-based architecture**: Web UI (Docker on VPS) controls Agent (local execution)
- **Outbound WebSocket only**: Agent connects to server, no firewall/port
  forwarding needed
- **Auto-registration**: Agent auto-registers to server on first run via
  Google OAuth
- **Local-only scripts**: Generated scripts never leave local machine
- **Evidence in Google Drive**: All screenshots/logs uploaded to Drive via
  service account

## Constraints

- Agent must have **Chrome available** (no option to use other browsers)
- No GitHub storage - all local execution
- Must use **zie-framework SDLC process** for backlog/spec/plan

## Design Principles

1. **Security first** - No secrets in code, use env vars and service accounts
2. **Local execution** - Tests run locally, results sync remotely
3. **Multi-user support** - Google OAuth for team access
4. **Zero configuration** - Agent auto-configures on first run
5. **Greenfield first** - New projects get clean slate
